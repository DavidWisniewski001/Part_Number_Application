# UI prototype source

These are the source files of the clickable prototype: https://claude.ai/artifact/3FHNbdEuzyktgNGggdv4pK

They are Design Component pages (`.dc.html`). They need the prototype viewer's runtime (`support.js`) and won't run on their own. Use them as a reference for layout, wording and behavior. The spec is `docs/UI_DESIGN.md`. All data in them is made-up sample data.
