# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-19

## Context
The project has several decisions (database ownership, numbering, sync strategy) that future maintainers need to understand.

## Decision
Record each significant decision as a short Markdown ADR in `docs/adr/NNNN-title.md`, with Status / Context / Decision / Consequences sections. Status is Proposed, Accepted, Superseded or Rejected.

## Consequences
Decisions are traceable. Changing a decision means writing a new ADR that supersedes the old one.
